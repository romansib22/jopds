# Changelog

Все заметные изменения в проекте JOPDS документируются в этом файле.

## [1.1.0] — 2026-10-14

Релиз производительности и стабильности каталога + миграция платформы на Java 21 / Spring Boot 3.5.

### Изменено
- Миграция платформы: Java 11 → 21, Spring Boot 2.7.18 → 3.5.10 (`jakarta.*`, Hibernate 6, Flyway 11, Tomcat 10.1, Lombok 1.18.48).
- Драйвер БД заменён на родной `mariadb-java-client`: Connector/J 9.x несовместим с MariaDB (падает на запросе JDBC-метаданных при старте Hibernate). Схема `jdbc:mysql://` сохранена, но новый драйвер принимает её только с параметром `permitMysqlScheme` — **при обновлении дописать его в `DATASOURCE_URL`** (в `.env` или переменных окружения).
- Пул соединений HikariCP вместо `DriverManagerDataSource`: раньше каждый запрос к БД открывал новое физическое соединение (пул `jopds-pool`: максимум 10 соединений, 2 простаивающих).
- Нестрогий поиск по книгам, сериям и именам авторов использует FULLTEXT-индексы вместо `LIKE '%…%'` (миграция V13, идемпотентна: `IF NOT EXISTS`).
- Импорт каталога выполняется стримингом по батчам: память O(размер каталога) → O(батч); ранее INPX-файл читался в память целиком.
- Скачивание книг отдаётся потоком, без буферизации данных книги в памяти.
- Импорт каталога пишется в staging-таблицы с атомарной заменой (`RENAME TABLE`): читатели не видят наполовину импортированный каталог, сбой импорта не разрушает рабочий каталог. Из каталоговых таблиц удалены FOREIGN KEY (миграция V14): приложение — единственный писатель каталога и поддерживает целостность само.
- Определение ID авторов при импорте — пакетными запросами вместо отдельного запроса на каждого автора (устранён N+1).
- Настройки языка пользователя загружаются одним запросом вместо запроса на каждую настройку (устранён N+1).

### Добавлено
- Эндпоинт `/import-from-path` выполняет импорт в фоне; повторный вызов во время импорта не запускает параллельный — возвращает статус текущего.
- Новый значок сайта (favicon).

### Исправлено
- Вложенность `application.yml`: блоки `datasource` / `jpa` / `flyway` ошибочно находились под ключом `server:` и молча не применялись — из-за этого не работали настройки Hikari-пула и батчинга JPA. Теперь применяются (признак — пул `jopds-pool` в логе старта).

### Безопасность
- Парсер аннотаций FB2 защищён от XXE: внешние сущности запрещены.

## [1.0.2] — 2026-07-01

### Добавлено
- Форма создания пользователя в разделе «Администрирование» вынесена в модальное окно (кнопка «Создать пользователя»).
- Вывод версии приложения в заголовке раздела «Администрирование» (мелким шрифтом под названием раздела).

### Исправлено
- Сканирование INPX в разделе «Администрирование» выполняется асинхронно: HTTP-запрос завершается сразу, прогресс отслеживается через опрос статуса. Устранён gateway timeout при длительном импорте каталога.
- Исправлено отображение статуса сканирования INPX после завершения: надпись «Идёт сканирование…» больше не остаётся на экране.
- Добавлена проверка INPX-файла перед чтением: размер, сигнатура ZIP и более понятные сообщения об ошибках при повреждённом архиве.
- Сборка `mvn package` проходит без запущенного MySQL: для тестов используется in-memory H2 (профиль `test`).
- Favicon заменён с `favicon.ico` на `favicon.png`: обновлены ссылки во всех шаблонах, добавлен публичный доступ к иконке в Spring Security.

### Изменено
- Эндпоинт `GET /api/inpx/import/status` возвращает объект со статусом, сообщением об успехе и текстом ошибки.

## [1.0.1] — 2026-01-25

### Добавлено
- Просмотр аннотации книги из FB2-файла (кнопка на карточке книги, модальное окно).
- Поиск авторов по комбинациям фамилия / имя / отчество из нескольких слов.

## [1.0.0] — 2025

### Добавлено
- Сканирование INPX-файла и загрузка каталога в БД.
- Поиск по автору, названию книги и серии.
- Веб-интерфейс, авторизация, избранные авторы, новинки избранных авторов.
- Скачивание книг из архивов (FB2, FB2.ZIP).
