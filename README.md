# jopds
OPDS каталогизатор на Java (Spring Boot)

Возможности:
- Сканирует inpx-файл, добавляет информацию о книгах в базу данных
- Осуществляет поиск по автору, названию книги, названию серии
- Имеет веб-интерфейс и систему авторизации

## Требования
- Java 21
- MariaDb не ниже 10.6

## Настройка
После установки MariaDb (apt-get install mariadb-server) необходимо создать пользователя:  
   sudo mysql -u root -p  (пароль по умолчанию пустой)

   mysql > grant all on *.* to 'jopds'@'localhost' identified by 'jopds';  
   mysql > flush privileges;  
   mysql > exit;  

Настройки приложения хранятся в .env -файле, который должен лежать рядом с .jar -файлом.  
Необходимо скопировать .env (в этом репозитарии он лежит в /usr/local/rs/jopds/) и отредактировать его в соответствии со своим окружением.

Настройки:  
SERVER_PORT - порт, который будет слушать приложение  
DATASOURCE_URL - путь к базе данных, рекомендуется использовать строку, как в примере, т.к. БД будет создана автоматически  
DATASOURCE_USERNAME - пользовател БД  
DATASOURCE_PASSWORD - пароль пользователя БД  
INPX_FILE_PATH - путь к inpx-файлу  
INPX_BOOK_DIRECTORY - путь к каталогу с книгами, если этот параметр не задан, то каталог будет определяться по inpx-файлу    
ADMIN_DEFAULT_PASSWORD - пароль администратора по умолчанию, при первом запуске приложения именно с помощью этого пароля можно будет войти в систему.

## Запуск
Запуск осущетвлять файлом launch.sh

#Установка как сервис в deb-системы:
1. скопировать jopds.service в /etc/systemd/system/ ,отредактировать файл на предмет пути к .jar
3. включить автозапуск: systemctl enable jopds.service
4. запустить: systemctl start jopds.service
5. проверить статус: systemctl status jopds.service

Логи: /usr/local/rs/jopds/log/jopds.log

После запуска приложение будет доступно по адресу http://<you-host-ip>:<порт, заданный в .env>    
Авторизуемся: логин: admin, пароль: пароль, заданный в .env (ADMIN_DEFAULT_PASSWORD)  

Рекомендую сразу создать пользователя (в разделе Администрирование) с ролью Администратор, авторизоваться под ним и деактивировать учетную запись admin  
В разделе Администрирование расположена кнопка "Запустить сканирование", которая запускает процесс сканирования inpx-файла.
В случае возникновения ошибок, они будут записаны в логи, а также отображены под кнопкой.  
В разделе настройки (шестеренка) можно ограничить поиск по языкам (русский, английский, другие)

Поиск:  
Поиск по автору поддерживается для следующих комбинаций:  
Фамилия  
Фамилия Имя  
Имя Фамилия  
Фамилия Имя Отчество  
Имя Отчество Фамилия  

Поиск по названию книги и серии поддерживается по тексту, без учета регистра.  
Чекбокс "Нестрогий поиск" работает по всем видам поиска. Ищет строки по вхождению искомого текста. Соответственно, по автору, названию книги, либо по серии.

Раздел Авторы: Каталог авторов.
Раздел Любимые Авторы: В данном разделе отображаются авторы, добавленные в список избранных. Также тут автора можно удалить из списка избранных.    
Добавление/удаление автора в список избранных:    
  В результате поиска автора, рядом с именем автора, правее количества книг, отображается кнопка "Добавить в избранное". Повторное нажатие удаляет автора из избранного.  
Раздел Новинки избранных авторов: В нём осуществляется поиск книг авторов, добавленных в список избранных, которые появились в каталоге, начиная с заданной в фильтре даты.
